# Requerimientos del proyecto parcial 2

## Tecnologías

- El proyecto debe desarrollarse con React.
- Se deben utilizar solamente Bootstrap, JavaScript y React Router, además de React.
- No se debe utilizar TypeScript ni tecnologías que no hayan sido enseñadas en clases.

## Páginas y navegación

- El proyecto debe tener cinco páginas: Inicio, Producto, Productos, Registro y Nosotros.
- `App.jsx` debe gestionar las rutas y la navegación entre las cinco páginas.
- `App.jsx` cumple la función de enrutador y no debe considerarse una página.

## Prioridades

- La prioridad principal es la página Registro, que debe incluir validaciones.
- No se deben considerar otras páginas o funcionalidades como parte de los requisitos prioritarios.
- Funcionalidades adicionales, como Carrito, son opcionales y no prioritarias.
